- 下一步：设计确认后 → git worktree → M0 实施计划（2-5分钟粒度任务）→ 子代理 TDD 执行
- 技术规格 `docs/TECH_SPEC.md` 完成，全部关键数值从参考源码核实（WebFetch 拉不动大文件时用 curl + jsdelivr 镜像）：
  - SSTV：VIS 头（1900Hz 300ms×2 引导 + 1200Hz 起停位 + 7 数据位 LSB + 偶校验）；16 个彩色模式全表取自 dnet/pysstv color.py
  - 重要发现：pySSTV Robot36 **没发 9ms 行同步**（SYNC 常量未用）→ pySSTV 不能做 Robot36 oracle，改用自造编码器+ISS 公开录音；Robot36 分隔脉冲频率与 Barber 规范也不一致 → 解码器分隔段只按时间窗不校验频率
  - SSDV：CRC32=IEEE 反射 0xEDB88320（Go 标准库直接可用）；RS=GF(256) poly 0x11D / FCR 112 / PRIM 11 / NROOTS 32 / pad 0，先 RS 后 CRC；JPEG 重组模板 SOI+2×DQT(65B)+SOF0(15B)+4×DHT(29/179/29/179)+SOS(10B)+扫描数据(0xFF 补 00)+EOI，宽高=MCU×16
  - 参考源码已存档 `docs/ref/`（rs8.c 318 行 / fsphil ssdv.c 1551 行 / bristol-seds ssdv.c+h），DQT/DHT 表体 M3 时从此提取不手抄
